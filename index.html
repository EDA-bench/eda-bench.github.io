EDA-bench
An Execution-Based Benchmark for Language Model Agents on Functional PCB Design

Dhruv Saini
Paper ↗Code & tasks ↗Results ↓Reference boards ↓

Abstract

Current language-model agents are increasingly able to operate electronic design automation tools and produce PCB designs. Existing evaluations, however, often test proxies for board functionality rather than directly simulating and analyzing board performance. We introduce EDA-bench, an execution-based benchmark for agentic KiCad PCB design.

EDA-bench contains 35 tasks derived from public open-hardware projects spanning connector breakouts, power-path circuits, microcontroller systems, motor drivers, camera and compute adapters, and high-density carriers. Each agent receives a prompt and a standardized KiCad environment, then must produce a complete KiCad project fulfilling all given requirements.

Submissions are graded by parsing the final PCB, extracting routes and traces, checking external ports and interfaces, testing for shorts, modeling trace parasitics, running SPICE simulations where applicable, and applying KiCad electrical-rule and design-rule checks.

Initial baselines show that EDA-bench is not saturated by the evaluated systems. Under the corrected grader, the strongest archived web-enabled configuration scores 1.48% overall, producing scorable projects for 21 of 35 tasks while failing most functional checks. These results show substantial room for improvement in language-model agents on verifiable PCB design tasks.
